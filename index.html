怎么打开　Linux/macOS 在终端运行 ./启动.sh（或 node server.js），Windows 双击「启动.bat」，本地服务自动启动并打开 http://localhost:8000。直接双击 index.html 是 file:// 页面，拿不到文件读写权限、无法自动读取——一定用启动脚本。
数据存在哪　就在同目录的 data.json 文件里。选择数据文件后改动会在半秒内写回，拷走这一个 JSON = 拷走全部数据。
自动读取　绑定过的数据文件会被记住，下次打开自动读取；每 1.5 秒检测一次文件变化，别处改了就热更新。若浏览器和编辑器同时改了同一份文件，会弹出冲突提示让你选，不会闷头覆盖。
换电脑 / 移动文件夹后　把 data.json 一起拷走，打开 index.html 重新点「选择数据文件」选它即可。
没绑定数据文件时　点「保存」会下载一份数据 JSON 备份。
快捷键　N 新增 · Ctrl/⌘+S 保存 · Ctrl/⌘+R 刷新 · Esc 关闭弹窗
